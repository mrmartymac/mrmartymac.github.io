When Docker / NoVNC Sessions are failing try to restart Docker

```bash
systemctl restart docker
```

If this does not resolve the issue, restarting MOAI may be needed.

```bash
cd /u/moai/server
./moai.py status
./moai.py stop
./moai.py start
```
### Final possibility
There was a stale file in `/u/moai/novnc` called `port.lock`.

That gets generated when someone tries to establish a connection to avoid port collisions

I had to remove that file to fix novnc

That should not be the first step taken, as it could be mid-connection attempt. But if docker is restarted and there are no sessions being created, then that file will just prevent new sessions
